# Logos

The Agency's mark and lockups. All SVG, drawn on a 64×64 grid.

| File | Use |
| --- | --- |
| `agency-mark.svg` | Full colour: maroon tile, white A, brass ring. App icon, favicon, sidebar, splash. |
| `agency-mark-ink.svg` | Single ink (`#1b1719` strokes, brass ring, no tile). Stamps, documents, anywhere the tile cannot sit. |
| `agency-lockup.svg` | Mark plus THE AGENCY in ink. Default horizontal lockup for light grounds. |
| `agency-lockup-reverse.svg` | Mark without its tile plus white wordmark. For maroon or dark grounds only. |
| `agency-wordmark.svg` | Wordmark alone, ink. Where the mark already appears elsewhere on the page. |

Ink: the mark's strokes are white on the maroon tile; in `agency-mark-ink.svg` they are `ink` and the ring is `brass`. SVGs are shown through `<img>`, which cannot inherit colour — pick the file that matches the ground rather than recolouring.

Clear space: one quarter of the tile width on every side. Minimum size 20px. The wordmark is currently set in the system font stack; convert it to outlines before any print use.
